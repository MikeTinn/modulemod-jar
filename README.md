# Modules Mod (Fabric 26.2)

Client-side mod with 5 modules: Scoreboard, Tab, Aspect Ratio, Chat, Hitbox.
Open the settings from Mod Menu (Mods -> Modules Mod -> Configure button).

Working modules: Scoreboard, Tab, Aspect Ratio, Chat (also /chatsearch), Hitbox, Zoom (hold C, scroll to adjust; rebind in Controls), Armor Status, Block Outline, Fog Customizer, Weather Changer, Motion Blur, FPS, Reach, Ping and Inventory HUD (drag them with the Move HUDs button next to the search bar). Run /modulesmod status in game to see which hooks are running.
Settings are saved to config/modulesmod.json.

Build: push to GitHub, Actions tab -> Build -> download the jar artifact.
